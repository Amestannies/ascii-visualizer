# ascii visualizer

A browser-based 3D visualizer that turns an uploaded photo into an ASCII glyph field and lifts it into 3D using AI depth estimation, built with Vite, TypeScript, Three.js and custom shaders.
Control it with your hands: webcam hand tracking (MediaPipe) feeds a custom-trained PyTorch gesture model that explodes, re-forms and rotates the field in real time.
